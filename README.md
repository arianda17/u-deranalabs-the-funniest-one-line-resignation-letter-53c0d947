# The Funniest One-Line Resignation Letter

`I quit — my houseplants have better work-life balance and they don't do standups`

Run it with `node main.ts` — the program prints the single entry line to stdout.

Plants don't need Slack, standups, or performance reviews — they just photosynthesize and chill. The real villain isn't the plants — it's the calendar invite for a sync that could've been a leaf.
